# 🐧 Linux Fundamentals

## 1. Introduction

Linux is an open-source operating system widely used in servers, cloud computing, software development, and cybersecurity.

Linux provides a command-line interface (CLI) that allows users to interact with the operating system through commands.

Learning Linux is an important step toward understanding cybersecurity and ethical hacking.

## 2. Learning Objectives

- Understand Linux operating system fundamentals.
- Learn basic Linux terminal commands.
- Understand the Linux file system.
- Learn files and directory management.
- Understand users and permissions.
- Explore Linux distributions.

## 3. What is a Linux Distribution?

A Linux distribution is an operating system built using the Linux kernel along with system utilities and applications.

Popular Linux distributions include:

| Distribution | Main Use |
|---|---|
| Ubuntu | General computing and development |
| Debian | Stable operating system |
| Kali Linux | Cybersecurity education and security testing |
| Fedora | Development and modern Linux technologies |
| Linux Mint | Beginner-friendly desktop computing |

## 4. Linux Terminal

A terminal is a text-based interface used to interact with the Linux operating system.

Users enter commands to perform different tasks.

## 5. Basic Linux Commands

### 1. pwd

Displays the current working directory.

```bash
pwd
```

### 2. ls

Lists files and directories.

```bash
ls
```

### 3. cd

Changes the current directory.

```bash
cd Documents
```

### 4. mkdir

Creates a new directory.

```bash
mkdir cybersecurity
```

### 5. touch

Creates an empty file.

```bash
touch notes.txt
```

### 6. cat

Displays file contents.

```bash
cat notes.txt
```

### 7. whoami

Displays the current logged-in username.

```bash
whoami
```

### 8. uname

Displays system information.

```bash
uname -a
```

### 9. clear

Clears the terminal screen.

```bash
clear
```

## 6. Linux File System

Linux uses a hierarchical file system that starts from the root directory `/`.

Important directories:

| Directory | Purpose |
|---|---|
| / | Root directory |
| /home | User home directories |
| /etc | System configuration files |
| /var | Variable data and logs |
| /tmp | Temporary files |
| /usr | User applications and utilities |

## 7. Linux File Permissions

Linux uses permissions to control access to files and directories.

The three basic permission types are:

- Read (r): Permission to read a file.
- Write (w): Permission to modify a file.
- Execute (x): Permission to execute a file.

Permissions can be assigned to:

- Owner
- Group
- Others

## 8. Linux in Cybersecurity

Linux is important in cybersecurity because:

- It provides powerful command-line tools.
- It supports network administration.
- It is widely used in cybersecurity laboratories.
- It helps users understand operating system behavior.
- It supports security monitoring and system administration.

## 9. Practical Learning Tasks

1. Open a Linux terminal.
2. Check your current directory using `pwd`.
3. List files using `ls`.
4. Create a practice directory using `mkdir`.
5. Create a text file using `touch`.
6. Display the file contents using `cat`.
7. Check your username using `whoami`.

Perform these exercises in your own Linux environment or an authorized learning lab.

Linux fundamentals provide essential knowledge for system administration, networking, cloud computing, and cybersecurity.

Learning terminal commands and understanding file permissions are important steps toward developing practical technical skills.
