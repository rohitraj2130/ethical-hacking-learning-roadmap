# 🐉 Kali Linux Fundamentals

## 1. Introduction

Kali Linux is a Debian-based Linux distribution designed for cybersecurity education, digital forensics, and authorized security assessments.

It provides a Linux environment with various tools used by cybersecurity professionals and students.

## 2. Learning Objectives

- Understand what Kali Linux is.
- Learn about its features and interface.
- Understand the Linux terminal.
- Explore the Kali Linux file system.
- Learn about virtualization.
- Understand responsible use of cybersecurity tools.

## 3. What is Kali Linux?

Kali Linux is an open-source operating system maintained by Offensive Security.

It is widely used for cybersecurity education and authorized security testing.

## 4. Key Features

- Open-source Linux distribution.
- Debian-based architecture.
- Command-line and graphical interfaces.
- Support for cybersecurity learning tools.
- Virtual machine compatibility.
- Extensive documentation and learning resources.

## 5. Kali Linux Desktop Environment

The graphical interface helps users interact with the operating system.

Important components include:

- Desktop
- Application Menu
- File Manager
- Terminal
- Settings
- Taskbar

## 6. Kali Linux Terminal

The terminal allows users to interact with the operating system through text commands.

Some basic commands include:

```bash
pwd
```
Displays the current directory.

```bash
ls
```
Lists directory contents.

```bash
whoami
```
Displays the current username.

```bash
date
```
Displays the current date and time.

```bash
uname -a
```
Displays system information.

## 7. Virtualization

Virtualization allows multiple operating systems to run on one physical computer using virtual machines.

Popular virtualization software includes:

- Oracle VirtualBox
- VMware Workstation

A virtual machine provides an isolated environment for educational experiments.
