# 🌐 Networking Fundamentals

## 1. Introduction

Computer networking is the process of connecting two or more computing devices to share data, information, and resources.

Networking is one of the most important foundations of cybersecurity and ethical hacking because it helps us understand how devices communicate with each other.

## 2. Objectives

- Understand basic networking concepts.
- Learn different types of computer networks.
- Understand IP addresses and MAC addresses.
- Learn the OSI and TCP/IP models.
- Understand common networking protocols.
- Explore basic networking commands.

## 3. Types of Computer Networks

| Network | Full Form | Description |
|---|---|---|
| PAN | Personal Area Network | Connects personal devices over a short range. |
| LAN | Local Area Network | Connects devices within a limited area. |
| MAN | Metropolitan Area Network | Covers a city or metropolitan area. |
| WAN | Wide Area Network | Connects networks over large geographical areas. |

## 4. OSI Model

The OSI (Open Systems Interconnection) model explains how data communication takes place through seven layers.

| Layer | Name | Main Function |
|---|---|---|
| 7 | Application | Provides network services to applications. |
| 6 | Presentation | Handles data format, encryption and compression. |
| 5 | Session | Manages communication sessions. |
| 4 | Transport | Provides end-to-end data delivery. |
| 3 | Network | Handles logical addressing and routing. |
| 2 | Data Link | Handles frames and MAC addressing. |
| 1 | Physical | Transmits bits through physical media. |

## 5. TCP/IP Model

The TCP/IP model is used for communication over modern networks.

Its four layers are:

1. Application Layer
2. Transport Layer
3. Internet Layer
4. Network Access Layer

## 6. IP Address

An IP (Internet Protocol) address is a logical address assigned to a device on an IP network.

There are two main versions:

- IPv4: Example: `192.168.1.10`
- IPv6: Example: `2001:db8::1`

IP addresses help identify devices and route data across networks.

## 7. MAC Address

A MAC (Media Access Control) address is a hardware-level network interface address used for communication on a local network.

Example: `00:1A:2B:3C:4D:5E`

## 8. Common Networking Protocols

| Protocol | Default Port | Purpose |
|---|---:|---|
| HTTP | 80 | Web communication |
| HTTPS | 443 | Secure web communication |
| DNS | 53 | Domain name resolution |
| FTP | 21 | File transfer |
| SSH | 22 | Secure remote administration |
| DHCP | 67/68 | Automatic IP configuration |
| SMTP | 25 | Email transmission |

## 9. Basic Networking Commands

The following commands help beginners understand their own computer's network configuration.

### Windows

```bash
ipconfig
```
Displays network configuration information.

```bash
ping 127.0.0.1
```
Tests the local TCP/IP stack using the loopback address.

```bash
nslookup example.com
```
Displays DNS lookup information for a domain.

```bash
hostname
```
Displays the computer's hostname.
